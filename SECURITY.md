# Security Policy

LazyDot moves and links files in your home directory, so bugs that can lose data or follow links unsafely are treated as security issues.

## Supported versions

| Version | Supported |
|---|---|
| 0.2.x | ✅ |
| < 0.2 | ❌ (please upgrade: 0.1.x has known data-loss bugs) |

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/itxmjr/LazyDot/security/advisories/new).

Include the LazyDot version, your OS, and steps to reproduce (a fake `$HOME` layout is ideal). You should get a reply within 7 days.
